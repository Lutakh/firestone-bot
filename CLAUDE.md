# Firestone Bot

This repository contains the original AutoHotkey v1.1 bot (repo root, `Functions/`, `Gui.ahk`)
and, on the `python-rework` branch, its Python port under `python/`.

Before doing any work on the Python port, read `docs/PYTHON_REWORK_PLAN.md`. It holds the
analysis of the AHK code, the architecture, the step-by-step execution plan, the open decisions
and the working conventions. Progress is tracked in `docs/PARITY.md` and measurements in
`docs/MEASUREMENTS.md` (created during execution).

Everything in the Python port is in English: code, comments, GUI text, docs, commit messages.
